# 🍔 Burger King Landing Page Clone

A landing page clone of the official **Burger King** website, built purely with **HTML5** and **CSS3**.

🌐 **Live Demo:** https://ajithnp.github.io/burger-king-landing-page/

---

## 📌 Features

- **Hero Banner:** Dynamic headline with direct ordering action buttons.
- **Promotional Offer Cards:** Well-aligned promo cards featuring Whopper® deals, free delivery, anniversary celebrations, and special offers.
- **Custom Brand Typography:** Styled using Burger King's custom *Flame* font family (Flame Regular, Flame Bold, Flame Sans).
- **Pure HTML & CSS:** Developed strictly without external JavaScript frameworks or heavy libraries.
- **Responsive Layout:** Flexbox-based alignment for smooth rendering across display resolutions.
- **Fixed Header & Navigation:** Sticky top header with brand logos and quick action buttons.

---

## 🛠️ Tech Stack

- **HTML5** - Semantic markup structure
- **CSS3** - Custom styling, Flexbox layout, font faces, and hover effects

---

## 📁 File Structure

```text
Burger king/
├── index.html            # Main HTML document structure
├── style.css             # Header, base styles, and hero section styling
├── main.css              # Promotional cards & main section grid styling
├── footer.css            # Footer layout & bottom navigation bar styling
├── flame-3-cufonfonts/   # Custom Flame font assets (woff2)
└── *.png / *.webp        # Images, logos, and graphic assets
```

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser or run with a local server extension (e.g., Live Server in VS Code / Antigravity).
